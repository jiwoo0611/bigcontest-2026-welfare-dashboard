# 사회적 고립 예방·대응 담당자 대시보드

2026 빅콘테스트 AI 활용 분야 출품 기획을 바탕으로 만든 **프론트엔드 시연 프로토타입**입니다. 아이디어명은 설정하지 않았습니다.

기존 배포: https://welfare-dashboard-vercel.vercel.app/

팀원 실행·파일 구조·협업 안내: [팀 안내서](docs/TEAM_GUIDE.md).

이 저장소는 기존 Vercel 프로토타입의 소스를 공유하기 위한 것입니다. 최근 추가 EDA 결과는 아직 연결하지 않았습니다.

## 실행

Node.js 20.9 이상에서 프로젝트 폴더를 열고 실행합니다.

```bash
npm ci
npm run dev
```

http://localhost:3001 접속. 종료는 Ctrl+C.

```bash
npm run typecheck
npm run build
```

정적 빌드 결과는 `out/`에 생성됩니다. `output: export`를 사용하므로 운영 미리보기는 `npx serve out` 또는 `python -m http.server 3002 --directory out`로 확인합니다. Next.js의 `next start`는 정적 내보내기와 함께 사용하지 않습니다.

## Vercel 배포

빠른 업로드: https://vercel.com/drop 에서 프로젝트 ZIP을 선택하고 로그인 후 배포할 수 있습니다. GitHub 연결을 통한 지속 배포는 아래 절차를 사용하세요.


1. 이 프로젝트의 파일을 별도 GitHub 저장소 루트에 올립니다. `node_modules`, `.next`, `.env`, `.vercel`은 제외합니다.
2. Vercel → Add New → Project → 해당 저장소 Import.
3. Framework Preset: **Next.js**. Root Directory: 프로젝트 폴더. Build Command: **npm run build**. Output Directory는 기본값 유지.
4. 환경변수 없이 Deploy. 초기 버전에는 API 키가 필요 없습니다.

CLI 배포: 프로젝트에서 `npx vercel`을 실행하고 로그인·프로젝트 설정을 완료합니다. 검토 후 `npx vercel --prod`로 운영 배포합니다.

배포 설정 참고: https://vercel.com/docs/frameworks/nextjs , https://nextjs.org/docs/app/guides/static-exports

## 화면

- 지역 분석: 지역·연령·기간 필터, 소비·통신 활동 추세, 업종 비중, 검토 후보, 원자료와 가상 인구 보정 비교
- 사례 검토: 페르소나 4개, 지지·반대 근거, 미확인 사항, 추가 질문, 상담 발언 연결, 담당자 의견 저장
- 지원 계획: 사례·지역·장벽·비용·방식·모집 필터, 가상 자원 후보, 공식 목록 링크, 문의 문장·역할 연습, 후보 기록
- 후속 관리: 상태·검색 필터, 참여 상태 변경, 피드백·다음 계획 저장, 변경 이력, 초기화
- 공통: CSV 내보내기, 반응형 화면, 빈 결과 안내, 저장·복사 오류 안내

## 데이터의 의미

`lib/data.ts`의 모든 수치·개인 사례·자원 카드는 가상입니다. 실제 EDA 수치나 실제 프로그램 목록으로 해석하면 안 됩니다. 자원 링크는 공식 목록의 출처이며, 개별 프로그램의 존재·비용·모집 상태를 검증한 링크가 아닙니다.

소비 원자료 지수는 가상 보정지수 × 가상 인구지수 / 100으로 생성합니다. 소비와 활동 변화는 선택 기간의 첫 월·마지막 월을 비교합니다. '지속 변화 후보'는 보정 소비 −5% 이하, 감소 지속 3개월 이상인 가상 기준입니다. 선택 조합 평균 차트는 인구 가중 평균이 아닙니다. 업종 차트는 7월·12월 고정 비중 자료로, 기간 필터와 독립적인 참고 차트입니다.

고객 수·이용 건수·주민 수를 혼동하지 않습니다. 집계 데이터에서 개인 명단을 추출하거나 개인의 고립 여부를 판정하지 않습니다. 에이전트 의견과 역할 연습은 사전에 작성된 예시입니다. 실시간 LLM은 연결되지 않았습니다.

## 저장

검토·후속 기록은 브라우저 localStorage에 저장됩니다. 팀원·기기 사이 공유되지 않으며 인증·권한·서버 데이터베이스는 없습니다. 가상 시연 기록만 입력하도록 구성했습니다.

## 실제 데이터·AI 연결

- `lib/data.ts`: 타입과 시연 데이터. 실제 분석값 연결 시 단위·지역 기준·기간·출처·보정 방식을 함께 관리하세요.
- `components/dashboard.tsx`: 화면, 필터, 기록 저장. 서버 저장 연결 시 localStorage 부분을 교체하세요.
- 실제 복지자원은 개별 URL·검증일·대상·비용·모집 상태·안내/동행 여부를 확인한 뒤 교체하세요.
- LLM 호출은 서버 API를 추가하고 근거 출처와 불확실성을 함께 반환하도록 구현하세요. 키를 클라이언트에 노출하지 마세요.
